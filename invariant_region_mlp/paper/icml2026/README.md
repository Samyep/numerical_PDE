# ICML 2026 tight draft

This directory tracks the submission-oriented rewrite of **Constraint-Aware Multilevel Picard Methods**.

The editorial goal is deliberately narrow: generic convergence theory is defensive rather than a headline contribution. The main text keeps (i) target preservation, (ii) a light work-order statement, and (iii) the structural counterexample rescue theorem. The samplewise convergence-inheritance argument is placed in the appendix, while a sharp consistency/complexity theory for batch-coupled retractions is left to future work.

`main.tex` is modularized into `sections/`. The ICML 2026 style file is included. The complete Overleaf package produced for this revision also contains the PDF figure assets; this repository copy uses placeholders when those assets are absent so that the text remains compilable and reviewable.

For anonymous ICML submission, do not place a link to this public repository inside the submitted manuscript.
