# Counterexample rescue experiment

This folder reproduces the Hutzenthaler--Nguyen (2025, arXiv:2506.23969v1) full-history MLP counterexample and adds invariant-region variants.

Run the main sweep with `counterexample_rescue.py`. The canonical reported protocol uses dimensions 2,5,10,20,50,100,200,500,1000; levels n=m in 1,2,3,4; and 512 paired estimator replicas. The raw baseline implements Eq. (6) without clipping or time flooring.

Key modes:
- `raw`: original full-history MLP.
- `recursive_subspace`: project the returned gradient to span(e1) at every recursive state.
- `generator_only`: project only before evaluating the nonlinearity.
- `final_only`: project only after the recursion finishes.
- `recursive_ball`, `recursive_box`: weaker certified supersets.
- `reduced_mc`: dimension-reduced Monte Carlo control.

`validate_rescue.py` checks the literal recursion and the exact Gaussian moment formula. `plot_counterexample.py` recreates PNG figures from the committed CSV/JSON results.

The repository stores all 252 configuration-level aggregate rows and per-replica observations for the four headline dimensions d=2,10,100,1000 at n=m=3. Larger intermediate NPZ state tensors are intentionally not versioned; they are regenerated by the main script.
